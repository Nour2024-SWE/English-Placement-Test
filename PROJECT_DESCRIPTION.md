# English Placement Test v7

A standalone web-based English placement assessment built with HTML, CSS, and vanilla JavaScript. The application presents a randomized 25-question test covering listening, grammar, vocabulary, reading, and advanced structures, then calculates a score, percentage, and CEFR-style estimated level.

It also provides answer review, bilingual result descriptions, browser-based result history, an admin/results view, and CSV export. The project is intended for educational use, classroom demonstrations, and language-assessment prototypes.

## Highlights

- Zero-dependency static web application.
- 25-question interactive placement test.
- Automatic grading and CEFR-style score mapping.
- LocalStorage result history.
- Teacher/admin result table and CSV export.
- Easy deployment through GitHub Pages.
